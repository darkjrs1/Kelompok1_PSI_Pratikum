# SILAPRO (Sistem Laporan Produksi) 
## Deskripsi 
SILAPRO adalah sistem dashboard produksi berbasis web untuk PT Pratama Abadi Industri yang menampilkan data produksi secara real-time dan terintegrasi. Sistem ini menggantikan rekap manual Excel dengan informasi seperti target, output, defect, dan efisiensi dalam satu tampilan, sehingga monitoring lebih cepat dan pengambilan keputusan lebih efektif.
